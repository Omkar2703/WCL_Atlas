# India Climate & Disaster Risk Atlas

An interactive dashboard visualizing drought severity, flood risk, and disaster history across India from 1901 to 2026 — built on the SPEI Drought Atlas, the India Flood Atlas, and EM-DAT.

## Features

- **Interactive choropleth map** at State, District, or Subdistrict level, color-coded by drought index (SPEI), flood fraction, flood area, or disaster event count — with a legend matching the exact thresholds shown.
- **Year slider** spanning 1901–2026, so you can watch conditions evolve over time.
- **Disaster event markers** plotted at their real reported location when available, falling back to the matched district/state centroid when the source data only gives a region rather than a point — visually distinguished (solid vs. faded/dashed) so it's never ambiguous which is which.
- **Region inspector** — click any polygon or pick a region from the dropdown to see cumulative disaster totals, deaths, affected population, and historical trend charts.
- **Built-in documentation page** covering every dataset, the full processing pipeline, and known data quirks — accessible from within the app.

---

## How it works

The project is split into two stages:

1. **`preprocess.py`** (run once, or whenever the raw source data changes) — reads the raw datasets, cleans them up, resolves entity names and IDs across sources, and writes analysis-ready Parquet and GeoJSON files to `data/processed/`.
2. **`app.py`** (the Streamlit dashboard) — reads only from `data/processed/`, never touches raw files at runtime.

Every stage of the pipeline is built to degrade gracefully: a missing or malformed input file logs a warning and produces an empty result for that piece, rather than crashing the whole pipeline.

For a full breakdown of each dataset, the exact processing steps, and known data-quality quirks (and how they're handled), see the **Documentation** page inside the running app (`pages/1_Documentation.py`).

## Datasets

| Dataset | Covers | Used for |
|---|---|---|
| **SPEI Drought Atlas** | State / District / Subdistrict boundaries + monthly SPEI z-scores, 1901–2020 | Drought severity index |
| **India Flood Atlas** | Annual flood fraction, flood area, and flood-risk components at State/District level | Flood extent & risk |
| **EM-DAT** | Individual disaster event records (floods, droughts, storms, etc.), 2000–2026 | Disaster event history & map markers |

See the in-app Documentation page for exact file names, formats, and how IDs/names are reconciled across sources.

## Setup

### 1. Clone and install dependencies

```bash
git clone https://github.com/Omkar2703/WCL_Atlas.git
cd YOUR-REPO
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Add the raw data

Place the raw source files under `data/raw/` following the structure documented in the in-app Documentation page (or the docstrings at the top of `preprocess.py`). This project does not redistribute the source datasets — download them from their original providers:

- SPEI Drought Atlas
- India Flood Atlas
- [EM-DAT](https://www.emdat.be/)

### 3. Run the pipeline

```bash
python preprocess.py
```

This generates everything under `data/processed/` — the Parquet summaries, GeoJSON boundaries, and the geocoded disaster event file.

### 4. Launch the dashboard

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501`.

## Known limitations

- The India Flood Atlas's own entity IDs don't match the ID scheme used in the SPEI Drought Atlas's lookup spreadsheets. When a direct match mostly fails, the pipeline falls back to a **positional match** (pairing sorted ID lists on both sides) — this is a heuristic, logged clearly when it triggers, and worth spot-checking rather than trusting blindly.
- Subbasin-level flood risk data exists in the source repo but isn't currently rendered on the map — there's no matching subbasin boundary/geometry file to plot it against.
- Disaster markers without exact coordinates (common for droughts, which EM-DAT usually records regionally) are approximated at the matched district or state's centroid, clearly marked as approximate on the map.
